# The Tab Icon — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `docs/superpowers/specs/2026-10-11-tab-icon-design.md`: the site's tab icon at 16, 32, 48 and 180 px,
linked from every page but the archived ABOUT.

**Architecture:** `scripts/make-icons.py` (Pillow and fontTools) writes `public/favicon.ico` from three hand-tuned grids
and `public/apple-touch-icon.png` from the fonts. Vite copies `public/` to the site's root. Six page heads gain two
links.

**Tech Stack:** Python (Pillow, fontTools, brotli), HTML, vitest.

## Global Constraints

- Colours come only from `tokens.css`: `--signal`, `--void`, and their dim mix (signal at 55 % on the void).
- `about-old.*` is never touched.
- Gates before commit: `npx tsc --noEmit`, `npx vitest run`, `npx vite build`.
